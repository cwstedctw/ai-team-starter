# material：老師的材料

公約規定 AI 只讀這裡的檔案、不寫進來。成品一律放 `workspace/outbox/`。

## 現在裡面有什麼

- `練習用/虛構訪談-X01.md`：**虛構**的失智症家庭照顧者訪談逐字稿，給工作坊練習用。人物、地點、情節都是編的。代號用 X，是為了不跟真實研究常用的代號（C01、P01）混在一起。

## 換成自己的材料前

1. **先把 `練習用/` 整個資料夾移走**（例如拖到桌面），免得虛構的稿子混進正式分析。
2. 檔案先另存成 `.txt` 或 `.md`：AI 讀純文字最穩；Word 檔要另外裝工具才讀得到。

## 研究資料能不能放進來？這一條說了算

**Private 不等於可以放受試者資料。** 要四個條件都符合才可以放：

1. **去識別化**：姓名、病歷號、聯絡方式不放；拼起來認得出人的資訊（住哪裡、職業、家庭成員、日期、少見的病史）也要處理掉。
2. **IRB 允許**：核准的計畫書、同意書範圍，允許用**每一家**會碰到這份資料的 AI 工具。接力模式會把資料同時送給 OpenAI 和 Anthropic。
3. **允許存放在 GitHub**：資料管理計畫和學校規範，允許把資料放在 GitHub 這種境外雲端。
4. **這個資料夾在 GitHub 上是 Private**。

有一條不確定，就先不要放，去問 IRB。審查中、合作單位要保密、還沒公開的計畫書，也先確認可以上傳再放。
